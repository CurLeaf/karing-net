## v3.0.0 - 2026-10-04

### 🚀 重大突破：完全自动切换

**核心改进**：
- ✅ **自动切换功能**：无需手动操作，系统自动优化节点
- ⚡ **切换速度**：30-60 秒内完成
- 🎯 **智能策略**：断开闲置连接 + 触发 URLTest 重测
- 🔔 **增强通知**：切换成功/失败都有反馈

**工作原理**：
1. 检测慢速节点（连续 3 次 < 256 KB/s）
2. 断开该节点的闲置连接（流量 < 1 KB/s）
3. 触发 URLTest 立即重测所有节点
4. URLTest 自动切换到快速节点
5. 验证切换结果并通知用户

**技术创新**：
- 在 URLTest 限制下实现自动切换
- 利用原生机制，无需修改 Karing 配置
- 最小化连接中断（仅影响闲置连接）
- 零维护成本

**新增功能**：
- `auto_switch_slow_node()` - 自动切换逻辑
- `_close_idle_connections()` - 断开闲置连接
- `_trigger_urltest_now()` - 触发立即测试
- `_get_current_node()` - 获取当前节点

**文档**：
- `UPGRADE_V3.md` - 升级指南和使用说明
- `AUTO_SWITCH_ANALYSIS.md` - 深度技术分析

## v2.0.0 - 2026-10-03

### 重大变更
- 🔄 架构重设计：从无效的自动切换改为监控通知模式
- ❌ 移除：所有尝试通过 API 切换 URLTest 代理组的代码
- ✅ 新增：节点性能追踪和数据库系统
- 📊 新增：智能推荐算法（多维度评分）
- 🔔 新增：慢速节点检测和通知功能

### 核心功能
1. **节点性能追踪**
   - 记录每个节点的延迟、吞吐量、成功率
   - 计算综合评分（0-100）
   - 多维度排序推荐

2. **智能监控**
   - 连续 3 次检测到慢速（< 256 KB/s）触发通知
   - 通知冷却期 15 分钟，避免骚扰
   - 推荐 Top 3 最优节点

3. **性能数据持久化**
   - SQLite 数据库存储历史数据
   - 支持长期趋势分析
   - 命令行工具查看统计

### 技术细节
- URLTest 代理组不支持通过 Clash API 手动切换节点
- 尝试切换会返回 `HTTP 400: selector_only`
- 改为监控性能，通知用户在 Karing 应用中手动切换
- 保留 URLTest 自动选择延迟最低节点的功能

### 文件变更
- `tunnel_watch.py`: 重构监控逻辑
- `node_tracker.py`: 新增性能追踪模块
- `node_stats.py`: 新增命令行统计工具
- `README.md`: 更新使用说明
- `KNOWLEDGE_BASE.md`: 技术知识沉淀
